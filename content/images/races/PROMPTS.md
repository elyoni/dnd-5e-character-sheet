# Race portrait prompts

Image-generation prompts used (or intended) for each race's reference photo in
`content/images/races/*.jpg`. Unlike the class photos (`content/images/classes/`),
these are deliberately **not** tied to any class — no weapons, no armor, no
spellcasting, no adventuring gear of any kind. The point is to show what the
race looks like as a person going about an ordinary day, so the Field Guide's
race cards don't quietly imply "this is what a fighter/wizard/etc. of this
race looks like."

Each prompt shows **a man and a woman of the race standing side by side** —
one image doing double duty to show the race's build/features across both
sexes, rather than one androgynous figure that risks reading as just "a man
with [race feature] bolted on" (this is what happened with the first Elf
attempt — see git history). Each half of the pair still follows the same
template shape as `../classes/PROMPTS.md`: one everyday (not combat/magic)
item resting near the shoulder/hip, a soft glowing aura outlining both
figures, "centered together with headroom" framing. Crop/resize to
900×1612 per `CONTEXT.md` before committing — a two-person composition
needs extra care to still read clearly at that crop.

Style matches the class prompts exactly (same closing style clause repeated
in every entry below) — a semi-realistic painterly alternative and a
Disney-ish exaggerated-cartoon alternative were both tried and rejected in
favor of sticking with the class prompts' original look, for consistency
across the whole Field Guide.
